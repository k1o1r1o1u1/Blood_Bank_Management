BLOOD BANK MANAGEMENT SYSTEM
FRONTEND DEVELOPER DOCUMENTATION

ROLE
You are responsible for developing the complete frontend/web interface of the Blood Bank Management System.

You will build the user interface using React.

IMPORTANT:
The frontend must NOT connect directly to MySQL.

The architecture is:

React Frontend
       |
       | REST API / JSON
       v
Node.js + Express Backend
       |
       | SQL
       v
MySQL

9. BLOOD ISSUE
==================================================

Page:

/issues

Blood issue workflow:

1. Select hospital request
2. Display required blood group
3. Display required quantity
4. Display available blood units
5. Select unit(s)
6. Confirm issue
7. Show success message

Example:

Hospital:
Apollo Hospital

Required:
O+

Quantity:
2 Units

Available:
5 Units

[Confirm Issue]

==================================================
14. DESIGN
==================================================

The UI should be:

- Clean
- Modern
- Professional
- Medical themed
- Responsive
- Easy to navigate

Suggested colors:

- White
- Dark Red
- Light Red
- Gray
- Black/Dark Gray

Avoid excessive animations.

The website should look like an actual hospital/blood-bank management system rather than a basic CRUD college project.

==================================================
15. IMPORTANT COLLABORATION RULE
==================================================

Do not assume database structure.

You will communicate with the backend through APIs.

The backend developer will provide:

- API endpoint
- HTTP method
- Request format
- Response format

Example:

POST /api/donors

Request:

{
    "name": "Rahul Sharma",
    "age": 23,
    "gender": "Male",
    "phone": "9876543210",
    "address": "Mysuru",
    "blood_group_id": 8
}

Response:

{
    "success": true,
    "message": "Donor created successfully",
    "donor_id": 25
}
